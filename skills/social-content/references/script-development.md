# Script development

Use when there is no script yet, or to improve an existing one. The result is an approved script and a filled-in brief, ready for storyboarding. Start from [the brief template](../assets/brief-template.md), saved in the project as `brief.md`.

Status: proposed 2026-11-05 and not yet tested on a real script. A better script raises the odds of holding attention. It cannot guarantee reach, so give no virality scores or predictions. When someone asks for "more viral", work through the checks below.

## Settle the story first

Fill in the story fields in `brief.md`: audience, takeaway, hook type, promise, payoff and share reason. Read [hooks](hooks.md) for the hook types. If the payoff or audience cannot be named, the idea is not ready to script.

## No script yet

1. **Gather real material.** Use the brief, source material and past posts first. Then ask at most three questions, for what only the user knows: what happened, who it was for, what changed. Do not invent stories, quotes, numbers or results.
2. **Offer three angles.** Give each one a hook type, an opening line, a payoff and a share reason. Make them differ in idea, not just wording. Recommend one.
3. **Write to the structure** for the video type, in the brand's voice.
4. **Run the checks** and fix what fails.
5. **Read it aloud,** then cut anything you would not say.

| Type | Beat order |
|---|---|
| Talking head | Surprising claim, why it matters, proof or example, the shift, what to do |
| Testimonial | Moment it changed, before, what happened, now |
| Motion explainer | Hook, setup, turn, mechanism, example, payoff |
| Quote | Setup phrase, turn phrase, hold. Never rewrite an attributed quotation |
| Event promo | Cold open on the best moment, arrival, people, details, peak, one breath, title, date and place. Write the on-screen lines and a job for each clip |

## Improve an existing script

Keep the writer's voice and meaning. Change what needs changing and leave what already works.

1. State in one line what the script is trying to do, and confirm it if unsure.
2. Run the checks.
3. Return, in this order:
   - What already works, so it stays.
   - The three problems that matter most, each with the line it affects.
   - The revised script, with changes visible rather than silently rewritten.
   - Three alternative openings, each using a different hook type.
4. Mark anything that needs a fact only the user has. Never fill the gap yourself.

## Checks

| Check | Ask | Usual fix |
|---|---|---|
| Subject | Can the viewer tell what this is, and that it is for them, in the first line? | Name the person or situation sooner |
| Gap | Does the opening leave a question they want answered? | Lead with the result, contradiction or feeling |
| Start | Does it open in the middle of things? | Cut greetings, context and the first sentence or two |
| Specific | Could a competitor post this unchanged? | Add the real detail, number or moment |
| Links | Do "but" or "therefore" fit between beats, or only "and then"? | Reorder, or cut the beat |
| Jobs | Does each beat change what the viewer knows or feels? | Cut beats that change nothing |
| Feeling | Does the emotion vary, or hold one note? | Add a short return of warmth, delight or surprise |
| Payoff | Does the script answer what the opening asked? | Fix the payoff or soften the hook. A fake gap costs trust |
| Ending | Does it stop when the payoff lands? | Cut the recap and shorten the sign-off |
| Share | What is someone saying when they send this? | Sharpen the recognition, usefulness or position |
| Spoken | Does it sound like speech when read aloud? | Shorter sentences, plainer words |
| Length | Does it fit the intended length? | About 2.5 spoken words a second is a rough first estimate; time a real read |
| True | Is every claim supportable? | Remove it, or ask for the source |

## Hand off

Once approved, put the script and story fields in `brief.md` and set its stage to `storyboard`. For a video, video-editor takes it from there. Write a beat list only if asked; the production skill owns the storyboard and final timing.
